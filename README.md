# Bills

Personal bill tracking app built with Vue 3, Vuex, and Tailwind CSS.

## Setup

```
npm install
```

## Development

```
npm run serve
```

## Testing

```
npm run test          # unit tests (Vitest)
npm run test:watch    # unit tests in watch mode
npm run test:e2e      # e2e tests (Playwright + Chromium)
```

Playwright requires browser binaries — run `npx playwright install chromium` on first setup.

## Build

```
npm run build
npm run lint
```
